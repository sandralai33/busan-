# 釜山小旅行 12/3–12/8

這是一個可由 GitHub Pages 免費託管的靜態網站。

## 發布方式
1. 在 GitHub 建立一個新的 **Public** repository，名稱建議 `busan-trip`。
2. 將本資料夾中的 `index.html`、`.nojekyll`、`README.md` 上傳至 repository 根目錄。
3. 開啟 repository 的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/(root)`，按 **Save**。
6. 等待 GitHub Pages 完成部署，網址通常是 `https://你的GitHub帳號.github.io/busan-trip/`。

## 注意
- 此網站為公開網站；任何知道網址的人都能瀏覽。
- 網頁待辦勾選目前儲存在各自裝置的瀏覽器，不會跨裝置或多人同步。
- 網頁目前包含原始行程資料，公開前請自行確認同行者同意公開其中資訊。
